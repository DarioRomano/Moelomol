# Documentation index

`docs/` is the project's memory. Keep it current; do not contradict it silently.

| Path | What it holds |
|---|---|
| `design/open-questions.md` | Decisions waiting for the project lead. Check first. |
| `decisions/` | ADRs: decisions that are expensive to reverse. |
| `roadmap.md` | Milestones and what blocks them. |
| `architecture.md` | How the code is built, plus the appendix of Godot APIs verified against the engine. |
| `design/` | Design documents: `story.md`, `art-direction.md`, `audio-direction.md`, `audio-prompts.md` (prompts for AI music and ambience), `asset-register.md`, and later the game systems. |
| `progress/` | One note per thread that changed something: what was done, what broke, how it was found. |
| `playtests/` | Checklists for things only a human can check. |
