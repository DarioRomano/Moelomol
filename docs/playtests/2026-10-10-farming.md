# Playtest: farming and the day–night cycle

**For:** the project lead. **Why:** the rules are tested automatically, but
the pace of the day, how the light feels, and whether farming is pleasant
can only be judged by playing. The slice is built on working assumption A
for Q21–Q27 (`docs/design/open-questions.md`). These checks are what should
settle those questions.

## 1. Build

The PR or release build. From the title press **F2** until the farm appears
(title → test card → renderer features → arena → farm), or launch with
`-- --start-scene farm_test`. Keyboard once, controller once.

| | Keyboard | Controller |
|---|---|---|
| Move | W A S D | Left stick |
| Use tool (hoe, watering can, seeds) | J | X / Square |
| Interact (harvest a ripe crop; the farmhouse door: sleep) | Space | A / Cross |
| Next / previous tool | E / Q | RB / LB |

Developer keys: **F8** sleep now, **F9** time ×30, **F3** performance
overlay. The top-right shows the day, time and phase; the top-left the tool
in hand and what you carry.
